# Eternal Invasion: Tank Edition

우주 배경의 실시간 진영 대결 캔버스 게임을 **4개 행성·16개 미션의 캠페인 게임**으로 완성한 버전. 아군/적군 기지가 병사를 자동 생산하며 레인을 따라 격돌하고, 플레이어는 탱크(오토파일럿 또는 수동)와 **배치 바(deploy bar)** 로 전장을 지휘한다. 단일 `index.html`(외부 의존성·에셋 없음, 바닐라 JS + Canvas 2D + WebAudio)로 구성된다.

- 손으로 짠 미션 16개(행성 4개 × 4): 미션마다 레인 수·지형(바리케이드, 파괴 가능한 다리, 점령 가능한 포탑/전초, 표적 건물)·해저드(용암 분출구, 이온 폭풍, 운석 소나기, 저중력, 붕괴하는 지반, 안개)·목표가 다르다
- 목표 8종: 기지 파괴 / 시간 생존 / 점령 후 유지 / 표적 파괴 / 수송차 호위 / 탱크 결투 / 붕괴 진지 방어 / 보스
- 유닛 8종(Rifleman, Shield Bearer, Rocket Trooper, Mortar Crew, Drone Pair, Field Medic, Heavy Walker, Sapper) + 각 진영의 전차, 각자 역할과 카운터가 있고 처음 나오는 적은 **NEW ENEMY 카드**로 카운터를 알려 준다
- 보스 3종(Iron Leviathan / The Colossus / Eternal Citadel) + 챔피언 결투(Warlord Kael): 다단계 페이즈, 파괴 가능한 부위, 전조가 보이는 공격
- 별 1~3개 평가, 크레딧 경제, 가라지(탱크·스킬·유닛·기지 업그레이드), 아미 덱, 행성 맵(해금), 엔딩, 엔드리스, 로컬 TOP 10(이니셜)
- 절차 생성 음악(맵, 행성 4곡, 보스 2곡, 엔드리스, 엔딩 + 승리/패배/보스격파/경고 징글)과 SFX, 음악/효과음 별도 토글(저장)
- 페이지를 열면 **즉시 1-1 미션이 AUTO로 시작**되고, 미션 사이 화면(정산 → 가라지 → 맵)은 아무도 건드리지 않으면 카운트다운 후 자동으로 넘어가 **방치해도 데모가 무한 순환**한다(패배하면 재도전, 캠페인이 끝나면 엔드리스로).

## 디자인 필러 (사용자 피드백 이력)

1. **시작 화면 게이트 금지** — 로드 즉시 플레이. 메뉴(맵/가라지/아미/점수/설정)는 HUD 버튼과 미션 사이에만 나온다.
2. **오토배틀이 핵심** — 양 군대가 알아서 싸우고, 탱크는 오토파일럿이 전선을 잡고 스킬을 쓰고 포격 링을 피하고 수리하러 돌아간다. 수동은 선택적 오버라이드이며 테스트 봇도 이 AI다.
3. **전략적 개입** — 자동 조준은 유지하되, 공급(Supply)으로 어떤 유닛을 어느 레인에 내보낼지, 언제 스킬을 쓸지가 승패를 가른다. 오토파일럿은 적 구성에 맞춰 카운터를 뽑는다.
4. (이번 지시) **"수정·연출만으로는 출시 수준이 아니다"** — 레벨 디자인이 있는 진짜 게임이어야 한다 → 미션 데이터, 신규 유닛/보스, 메타 진행, 엔딩.
5. **공정한 전조** — 보스·해저드의 모든 강공은 링/레인 띠/수직 기둥/먼지 파동으로 먼저 보이고, 오토파일럿도 같은 목록을 보고 피한다(보이는 것 = AI가 반응하는 것).

## 조작

| 입력 | 동작 |
| --- | --- |
| `A` `D` / `←` `→` | 탱크 이동. AUTO 중에는 누르는 동안만 오토파일럿보다 우선(뗀 뒤 약 1초 후 복귀), AUTO OFF에서는 완전 수동 |
| `W` `S` / `↑` `↓` | 탱크가 서 있는 레인 변경(레인은 위쪽이 능선/후방) |
| 마우스 누르고 있기 | 그 위치로 주포 조준 + 발사(오버라이드). 떼면 다시 자동 조준 |
| `1` `2` `3` / 스킬 링 | Orbital Strike(40 EN) / EMP Burst(30 EN) / Missile Salvo(50 EN). 마우스가 필드 위에 있으면 Strike는 그 지점에 떨어진다 |
| `4`~`8` / 카드 클릭 | 덱의 n번째 유닛 배치(공급 소모). 카드에 공급 비용과 쿨다운이 표시된다 |
| `L` / HUD `LANE` 칩 | 배치 레인 선택(A = 자동: 가장 압박받는 레인) |
| `R` `B` / WARP 링 | 기지로 워프(3초 채널링) — 기지 근처에서 HP/에너지 자동 회복 |
| `T` / HUD `AUTO` | 오토파일럿 켜기/끄기(이동·배치·스킬·회피·귀환 전부) |
| `P` `Esc` / HUD 일시정지 | 일시정지 메뉴(창 blur·탭 전환 시 자동). 하위 화면에서는 `Esc` = 뒤로 |
| `M` / HUD 메뉴 | 메뉴(재개·재시작·맵·가라지·아미·점수·설정·도움말, YouTube/Kitscript 링크) |
| 터치 | 좌하단 조이스틱(좌우 이동, 위/아래로 튕기면 레인 변경). 카드·스킬 링·WARP는 탭. 조이스틱을 만져도 오토파일럿의 배치·스킬은 유지된다 |

AUTO가 켜진 채 아무 입력이 없으면 미션 사이 화면(정산 8s → 가라지 7s → 맵 6s, 실패 시 재도전 화면 3.4s)이 자동 진행된다. 입력이 있으면 카운트다운이 리셋되고, AUTO를 끈 사람은 직접 버튼을 눌러야 하며 30초 이상 방치되면 다시 자동 진행으로 돌아간다. 좁은 화면(≤720px)에서는 YouTube·Kitscript 아이콘이 메뉴 안의 링크로 옮겨간다(BUNTGAMES 표기는 유지).

## 게임 규칙

- **필드**: 고정 논리 해상도 1200×600, 창 크기에 맞춰 레터박스·HiDPI 스케일. HUD(미션·목표·기지·공급·크레딧)와 명령 바(배치 카드, 레인, 스킬, 탱크 상태)는 DOM이라 375px 폰에서도 읽히고, 세로 화면에서는 필드 아래에 명령 바가 붙는다. 고정 60Hz 시뮬레이션.
- **레인**: 미션마다 1~3개의 도로. 지상 유닛은 한 레인에서 전진·교전하며 서로 막는다(줄 서서 싸움). 위쪽 레인(능선)에서 아래 레인을 쏘면 사거리 +12%. 탱크는 호버라서 레인을 옮겨 다니고 다리가 끊겨도 건넌다.
- **기지**: 아군/적군 기지가 무료 소총병을 계속 내보낸다(미션별 주기). 아군 기지는 `Base Turret` 업그레이드로 자동포를 얻는다.
- **공급(Supply)**: 시간당 자동 재생(+처치 시 소량 환급)되는 자원으로 배치 바의 유닛을 산다. 카드마다 쿨다운이 있고 아군 지상 유닛은 최대 40기(전장이 읽히게).
- **탱크**: 주포(자동 조준·연사) + 유도 미사일(별도 쿨다운). 죽으면 6초 뒤 기지에서 재출격. 기지 반경 92px 안에서는 HP·에너지가 빠르게 회복.
- **스킬**: `Orbital Strike`(밀집 지역에 8~10발, 다리도 부순다) / `EMP Burst`(반경 내 적 기절 + 방패 해제 + 부위 기절) / `Missile Salvo`(6~10발 유도, 공중 포함). 에너지는 시간·킬 소량으로 재생, 이온 폭풍 중에는 재생 정지.
- **데미지 상성**: 무기 종류 × 대상 종류 배율표(아래 유닛 표). 로켓 ×2.4(차량), 소총 ×0.45(차량), 박격포 ×1.3(보병), 공병 ×2.4(구조물), 방패병은 정면 직사탄 −78%(박격포·공병·공중은 무시).
- **별**: ★ 클리어 / ★★ 기지가 45% 이상 유지 / ★★★ 기지 72% 이상 + 탱크 손실 ≤1 + 파 타임 이내(파 타임이 없는 미션은 기지 상태만).
- **막힘 방지(현장 지원, Mercy)**: 같은 미션을 연속으로 실패할 때마다(최대 4단계) 시작 공급 +8, 공급 재생 +8%, 기지 장갑 +8%, 적 체력 −5%를 받고 시작 시 안내 토스트가 뜬다. 실패해도 처치 크레딧의 50% + 보상의 8%를 받는다.

## 행성 / 미션

행성마다 배경·팔레트·음악과 **시그니처 메커니즘**이 있고, 미션마다 새 요소를 하나씩만 도입한다. 미션 데이터는 `MISSIONS` 배열(레인 정의, 구조물, 해저드, 웨이브 스크립트, 챔피언, 목표, 별 기준, 소개 카드)이다. 웨이브는 `P(시각, 레인, {유닛: 수})`로 쓴 "푸시" 목록이며 `sz`(물량)·`em`/`ed`(체력/피해) 배율로 난이도를 맞춘다.

## 오토 파일럿 AI (데모이자 테스트 봇)

- **탱크 이동**: 아군 최전선 조금 앞에 자리 잡고(군대가 있는 레인 우선, 적 압박이 큰 레인 가산), 로켓병은 사거리 밖(222px)에서 견제, 전투 중엔 사거리의 82%로 접근. 목표별 전용 행동: 점령(전초 위에 서서 3인분으로 점령), 표적(가장 가까운 표적에 접근), 호위(수송차 옆), 결투(챔피언과 0.86 사거리 유지, 가끔 레인 이동), 보스(부위 우선순위: 포탑·이미터·다리 → 방어막 → 코어).
- **회피**: 렌더러가 그리는 것과 같은 전조 목록(포격 링, 벼락 링, 분출구 균열, 레인 띠, 수직 기둥, 충격파, 날아오는 박격포탄)을 반응 시간(0.2s) 이후에 보고 옆으로 비키거나 레인을 바꾼다.
- **스킬**: EMP(주변 3기 이상·체력이 낮을 때·가드 챔피언·보스 부위), Strike(밀집 4+·다리 위 적·표적/포탑/보스 부위·적 기지), Salvo(적 4기 이상·공중 2기 이상·챔피언·보스). 에너지 예약 규칙 있음.
- **귀환/수리**: 체력 30% 미만(로켓 2기 이상이면 50%)이면 후퇴, 멀리 있으면 워프.
- **배치**: 34프레임마다 적 구성(로켓·차량·공중·방패·박격포·의무병)에 따라 유닛별 점수를 매겨 고르고, 레인은 압박·지원 필요·구조물·호위·보스 위치로 정한다. 끊긴 다리/붕괴 레인은 피한다.
- **군대 집결**: 공격 미션에서는 집결선에 모였다가 충분한 수가 되면 함께 전진한다.
- **완벽하지 않음**: 새 위협은 반응 시간 뒤에야 보고, 9프레임마다만 계획을 갱신하고, 위치 오차(±14px)·가끔 오판(5%)이 있다. **캐주얼 프로필**은 반응 0.5s·26프레임 갱신·위치 오차 40px·스킬은 20%만·회피 50%·워프 없음·배치 2.4배 느림.

### 알려진 한계 / 판단

- 밸런스는 봇 기준이다. 사람의 수동 플레이(특히 회피·스킬 타이밍)로 보스가 더 쉽거나 어려울 수 있어 Mercy(연속 실패마다 최대 4단계)로 안전망을 뒀다.
- 초반 미션(1-1~1-4, 3-2)은 튜토리얼 성격이라 봇에게 쉽다(캐주얼 봇이 높은 물량에서만 구분됨).
- 오디오는 절차 생성이라 실제 청감 확인은 하지 못했고 헤드리스에서는 오류 없이 스케줄링되는지만 확인했다.
- 파 타임(3성 조건)은 봇 평균 클리어 시간에 맞춰 잡았다. 탱크 손실 ≤1 조건 때문에 3성은 의도적으로 까다롭다.
