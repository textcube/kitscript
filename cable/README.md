# Cable Car Defense

설산 케이블 위를 오가는 케이블카(포대)로 지상의 침입자를 요격해 사다리·송전탑을 지키는 **10스테이지 캠페인 디펜스 게임**. 단일 파일(`index.html`)·외부 의존성/에셋 없음(그래픽은 Canvas 절차 생성, 오디오는 WebAudio 절차 생성).

- 손으로 짠 스테이지 10개(지형·시야·사다리·송전탑·눈사태가 스테이지마다 다름), 적 9종(+분열체), 보스 2종(중간 보스 예티 / 최종 보스 공성 전차)
- 별 1~3개 평가, 코인 경제, 업그레이드 상점, 스테이지 맵(해금), 엔딩, 엔드리스 모드, 로컬 TOP 10 점수표
- 절차 생성 음악(맵/스테이지 3종/보스 2종/엔딩/엔드리스 + 승리·패배 징글)과 SFX, 음악·효과음 토글(저장)
- 페이지를 열면 **즉시 1스테이지가 오토 모드로 시작**되고, 스테이지 사이 화면은 아무도 건드리지 않으면 카운트다운 후 자동으로 넘어가 방치해도 데모가 무한 순환한다.

## 디자인 필러 (사용자 피드백 이력)

이전 두 차례 개선에서 사용자가 직접 정리한 재미의 축이며, 이번 "출시 수준" 개편에서도 그대로 유지했다.

1. **시작 화면 게이트 금지** — 로드 즉시 플레이. 메뉴(맵/상점/점수/설정)는 HUD 버튼과 스테이지 사이에만 나온다.
2. **유능한 AI가 필드 전역에서 요격하는 모습을 구경하는 것이 핵심 재미** — 오토 파일럿이 캠페인 전체(상점 포함)를 스스로 플레이한다. 테스트 봇도 이 AI다.
3. **수동 모드는 "위치만 조작"** — 케이블카 위치만 옮기면 Drop/Arc는 정렬 시 자동 발사, Arc의 좌우 180px 고정 오프셋은 의도된 포지셔닝 요소, 클릭/탭은 선택한 CC 무기(Freeze/Pit/Sticky) 투척.
4. (이번 지시) **"수정·연출만으로는 출시 수준이 아니다"** — 레벨 디자인이 있는 진짜 게임이어야 한다 → 스테이지 데이터, 신규 적/보스, 메타 진행을 추가.

## 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 (AUTO OFF) | 케이블카 위치 지정. 정렬되면 Drop/Arc 자동 발사 |
| `1`~`5` / 슬롯 클릭 | 무기 선택. 1·2는 주력(Drop/Arc), 3·4·5는 CC를 "장전" |
| 클릭 / 탭 | 장전한 CC 무기를 그 지점에 투척 (AUTO OFF에서 Drop/Arc 선택 중 클릭은 즉시 1회 강제 발사) |
| `Space` / `Enter` | (수동) 선택 무기 강제 발사 |
| `A` / AUTO 버튼 | 오토 파일럿 토글 |
| `P` / `Esc` / 일시정지 버튼 | 일시정지 (탭 전환·창 blur 시 자동). 하위 화면에서는 Esc = 뒤로 |
| `M` / 메뉴 버튼 | 메뉴(재개·재시작·맵·상점·점수·설정·도움말) |
| 터치 | 드래그 = 이동(AUTO 자동 해제), 슬롯 탭 후 필드 탭 = CC 투척 |

AUTO가 켜진 상태에서 아무 입력도 없으면 스테이지 사이 화면(정산 8s → 상점 11s → 맵 7s, 실패 시 재도전 화면)이 자동 진행된다. 입력이 있으면 카운트다운이 리셋된다. AUTO를 끈 사람은 직접 버튼을 눌러야 하며, 30초 이상 방치되면 다시 자동 진행으로 돌아간다.

## 게임 규칙

- 적은 지상을 걸어 사다리(또는 송전탑)로 향한다. 사다리 꼭대기에 닿으면 **케이블 포인트**가 깎이고(Brute 3, 사퍼 폭파 2), 0이 되면 스테이지 실패(재도전 무제한).
- 스테이지마다 케이블 포인트가 다르다(5~9, 업그레이드로 최대 +3). 같은 스테이지에서 2·4번 연속 실패하면 재도전 시 +1·+2 "현장 수리"를 받는다(막힘 방지).
- **별**: ★ 클리어 / ★★ 피해 ≤ 스테이지 기준(2~4) / ★★★ 피해 0 + 기준 시간 이내. 별이 많을수록 보너스 코인.
- **무기 해금**: Drop(시작) → Arc(1스테이지 클리어) → Freeze(2) → Sticky(3) → Pit(4).

### 무기

| 무기 | 특성 |
| --- | --- |
| Drop | 수직 낙하. 빠르고 저렴. 방패에 튕기고, 글라이더는 회피 |
| Arc | 포물선 + 스플래시. 카 기준 좌우 180px 고정 오프셋. 방패·비행체·아머에 유효 |
| Freeze | 범위 빙결(사다리 위 적도 정지). 보스는 "스태거" 후 받는 피해 x2 |
| Pit | 지상 함정, 걷는 적 고정. 레벨 3+ 지속 피해. 중량/보스는 저항 |
| Sticky | 넓은 감속 웅덩이 |

## 스테이지

지형은 `[x비율, 높이]` 키포인트, 시야·눈사태·송전탑 등은 스테이지 데이터(`STAGES`)로 정의된다. 웨이브는 `g(type, count, gapMs, {t, side, to, hp})` 그룹의 배열이고, 이전 웨이브가 다 나온 뒤 `rest`ms가 지나고 잔존 적이 `left` 이하이거나 `wait`ms가 지나면 다음 웨이브가 시작한다(휴식→클라이맥스 페이싱). 스테이지 4 이후는 `dens`(밀도)·`tempo`(간격)·`hpm`(체력 배율)로 난이도 곡선을 만든다.

## 보스

- **The Yeti** (6스테이지, 체력 200): 페이즈 1 — 카를 노리는 눈덩이(붉은 원 + 예고선 ~1.5s, 맞으면 기절). 페이즈 2(66%) — 서리 아머(Drop 튕김, Arc로만 파괴) + 증원. 페이즈 3(33%) — 돌진(예고선 후 질주, Pit로 저지) + 이중 눈덩이. 사다리에 닿으면 매 1.8s마다 사다리를 내려쳐 **-2**. Freeze로 스태거(받는 피해 x2), 아머 파괴 후에도 x2 노출.
- **Glacier Breaker** (10스테이지, 체력 260): 페이즈 1 — 전면 장갑(Drop 튕김, Arc로 파괴) + 작살(카 조준, 예고 ~1.2s) + 호위병. 페이즈 2(66%) — 장갑 해제, 글라이더·방패병 소환, 작살 2발. 페이즈 3(33%) — 오버드라이브: 전방 눈사태(경고 구역), 돌진, 작살 3발, 사퍼/러너/글라이더 소환. 사다리에서 램 **-3**.
- 보스 사망 시 충격파로 호위병이 전멸한다.

## 경제와 업그레이드

- 코인: 처치(적별 1~16, 보스 200/400) + 스테이지 보너스(45~350, 재플레이 50%) + 별 보너스. **실패해도 처치 코인의 35%(salvage)**를 받아 막힘 없이 조금씩 강해진다.
- 업그레이드(7종): Drop Cannon / Arc Mortar (쿨다운·피해·스플래시) L1~5, Freeze / Sticky / Pit (쿨다운·범위·지속) L1~5, Car Motor(속도) L1~5, Cable Armour(모든 스테이지 케이블 +1, 최대 +3).
- 비용(다음 레벨): Drop 70/150/260/400, Arc 80/170/280/420, CC 70/140/230/350, Motor 60/130/220/340, Armour 110/230/400. 캠페인 전체 수입으로 약 절반~2/3를 구매할 수 있다.
- 오토 파일럿의 자동 상점은 고정 빌드 순서(Drop2 → Arc2 → Armour1 → Motor2 → Drop3 → Freeze2 ...)로 살 수 있는 만큼 산다.

## 검증 (헤드리스 Chromium + Node 시뮬레이터, 실제 결과)

**밸런스 (오토 파일럿, 시드 20개, 기본 설정 = god 없음)**

- 상점을 쓰는 오토 캠페인: **20/20 완주**. 스테이지별 1회차 클리어율 S1~S8 100%, S9 95%, S10 90%. 최종 시도 평균 피해: S1~S6 ≈ 0, S7 0.8, S8 4.8, S9 2.2, S10 5.9 (케이블 7~12). 별 평균: S1~S6 3.0, S7 2.6, S8 1.1, S9 2.0, S10 1.2.
- 업그레이드 없음(전부 L1, 무기는 진행도대로 해금): S1~S3 20/20, **S4 8/20, S5 이후 0/20** → 상점 없이 연쇄 플레이하면 평균 3.5스테이지 후 패배. 반대로 초반 스테이지 수입으로 필요한 업그레이드를 살 수 있어 노가다는 필요 없다(오토 캠페인은 재플레이 없이 완주).
- 캐주얼 사용자 대용(조준 오차 2배·재타깃 2.75배 느림·CC 미사용) + 상점: 19/20 캠페인 완주(스테이지당 10회 이내), 벽은 보스(S6 평균 2.2회, S10 4.6회). 실제 UI에서는 실패 시 코인 salvage와 현장 수리(+1/+2)가 추가로 도와준다.
- 장시간: 엔드리스 30분(god / 일반) 시뮬레이션 NaN 0, 예외 0, 배열 상한(적 ≤ 25, 투사체 ≤ 15, 스폰 큐 ≤ 49) 유지, god 최고 53웨이브 / 일반 플레이는 6회 사망·최고 19웨이브. 실제 브라우저(파티클 포함) 22분 엔드리스도 NaN·에러 0, 파티클 ≤ 155.

**플로우 (Playwright, 23개 항목 전부 통과, 콘솔 에러/경고 0)**
