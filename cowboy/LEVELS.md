# Cowboy 100-Level Campaign

100개의 고유 전투를 여섯 지역에서 진행합니다. 레벨 제목은 간결하게 유지하고, 지역은 화면의 챕터 표기와 배경으로 구분합니다. 배경은 기존 6종을 재사용합니다. 5레벨마다 보스가 등장하고, 100레벨 보스를 쓰러뜨리면 101레벨에서 첫 원정을 cycle 1로 다시 시작합니다.

| Levels | 지역 (KO / EN) | 지역 대장 (KO / EN) |
|---:|---|---|
| 1–15 | 노을 협곡 / SUNSET MESA | 붉은 모래 대장 / Red Sand Marshal |
| 16–30 | 먼지바람 마을 / DUSTWIND TOWN | 무법자 잭 / Outlaw Jack |
| 31–50 | 달빛 철도 / MOONLIGHT RAIL | 철갑 기관사 / The Iron Conductor |
| 51–65 | 붉은 바위 관문 / REDROCK GATE | 협곡의 파수꾼 / Canyon Warden |
| 66–80 | 별빛 수정 광산 / STARLIGHT MINE | 수정 골렘 / Crystal Golem |
| 81–100 | 황혼의 요새 / TWILIGHT CITADEL | 황혼의 군주 / The Dusk Lord |

## Difficulty curve

- 레벨 1–100은 각기 다른 이름, 힌트와 전술 유형을 갖습니다. 레벨 101은 레벨 1 콘텐츠로 돌아가 cycle 1을 시작합니다.
- 기본 quota는 레벨·공세 단계에 따라 대략 7–17명이며 생성 간격은 약 1.2–1.8초입니다. 적 유형 가중치는 레벨마다 합계 1입니다.
- 기본 적 HP 배율은 약 0.78–1.25입니다. 보스 HP는 360부터 완만하게 올라갑니다. 고정 무기 피해량을 감안해 지수형 체력 상승은 사용하지 않습니다.
- 100레벨은 피날레 전용으로 quota 20, 생성 간격 900ms, 다수 적 유형이 고르게 섞인 가중치, 기본 계산보다 18% 높은 보스 체력(약 806)을 사용합니다.
- cycle마다 quota는 최대 3명, 적 HP 및 보스 HP는 최대 30%까지 완만하게 증가합니다. 생성 간격 감소는 cycle당 3.5%이며 최소 700ms입니다.
- 지역 경계 보스는 15, 30, 50, 65, 80, 100레벨입니다.
