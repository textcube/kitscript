# Eternal Invasion: Space Edition (Space Auto-Battle)

세로형 오토배틀 스페이스 인베이더를 **17스테이지 캠페인 슈팅 게임**으로 완성한 버전. 단일 `index.html`(외부 의존성·에셋 없음, 바닐라 JS + Canvas 2D + WebAudio)로 구성된다.

- 5개 섹터 × 3~4스테이지(총 17스테이지) + 보너스 2스테이지, 스테이지마다 손으로 짠 편대·진입 경로·다이브·타이밍·가르침(teaching intent)
- 기본 3티어 + 신규 행동형 적 8종(Weaver, Diver, Aegis, Splitter, Sniper, Carrier, Phantom, Plated) + Shield Core/Pylon, 각자 **NEW ENEMY 카드**(카운터 포함)
- 섹터마다 마지막에 **다단계 보스**(부위 파괴·전조·공정한 탄막) 5종, 마지막은 최종 보스 The Overlord
- 파워업 6종(산탄/연사/실드/폭탄/추가 기체/옵션 드론), 별 1~3개 평가, 크레딧 경제, 영구 업그레이드 상점 8종, 섹터 맵(해금), 엔딩, 엔드리스 모드, 로컬 TOP 10(이니셜)
- 절차 생성 음악(맵·섹터 5곡·보스 2곡·보너스·엔드리스·엔딩 + 승리/패배/보스격파/경고 징글)과 SFX, 음악/효과음 별도 토글(저장)
- 페이지를 열면 **즉시 1-1스테이지가 AUTO로 시작**되고, 스테이지 사이 화면은 아무도 건드리지 않으면 카운트다운 후 자동으로 넘어가 **방치해도 데모가 무한 순환**한다(패배하면 재도전, 캠페인이 끝나면 엔드리스로).

## 디자인 필러 (사용자 피드백 이력)

1. **시작 화면 게이트 금지** — 로드 즉시 플레이. 메뉴(맵/상점/점수/설정)는 HUD 버튼과 스테이지 사이에만 나온다.
2. **오토배틀이 핵심** — 함선이 스스로 목표를 고르고, 리드 샷을 쏘고, 탄을 피하고, 파워업을 줍고, 상점에서 쇼핑한다. 수동은 선택적 오버라이드일 뿐이며 테스트 봇도 이 AI다.
3. **고전 인베이더의 전략성 유지** — 편대는 "가장 바깥쪽 생존기" 기준으로 벽에서 반사한다. 가장자리 열부터 지우면 이동 폭이 넓어져 하강 횟수가 줄어든다. 발사각은 수직 기준 ±15% 콘으로 제한된다(그래서 위치 선정이 중요).
4. (이번 지시) **"수정·연출만으로는 출시 수준이 아니다"** — 레벨 디자인이 있는 진짜 게임이어야 한다 → 스테이지 데이터, 신규 적/보스/파워업, 메타 진행.
5. **공정한 탄막** — 보스의 모든 패턴은 반드시 함선이 통과할 틈을 가지며, 시뮬레이션으로 증명한다(아래 검증).

## 조작

| 입력 | 동작 |
| --- | --- |
| `←` `→` / `A` `D` | 수동 이동(누르는 동안 오토 파일럿보다 우선, 뗀 뒤 0.8초 후 오토 복귀) |
| 마우스 드래그 / 터치 드래그 | 포인터 위치로 이동(수동 오버라이드). 터치에서는 **두 번째 손가락 = 폭탄** |
| `B` / `Space` / `↑` / HUD 폭탄 버튼 | 폭탄 사용(보유분, 최대 3개) |
| `T` / HUD `AUTO` 버튼 | 오토 파일럿 ON/OFF(OFF여도 조준·사격은 자동, 이동만 수동) |
| `P` / `Esc` / HUD 일시정지 | 일시정지(창 blur·탭 전환 시 자동). 하위 화면에서는 `Esc` = 뒤로 |
| `M` / HUD 메뉴 | 메뉴(재개·재시작·맵·상점·점수·설정·도움말, YouTube/Kitscript 링크) |
| `Enter` / `Space` | NEW ENEMY 카드 닫기 |

AUTO가 켜진 채 아무 입력이 없으면 스테이지 사이 화면(정산 8s → 상점 9s → 맵 6s, 실패 시 재도전 화면 3s)이 자동 진행된다. 입력이 있으면 카운트다운이 리셋되고, AUTO를 끈 사람은 직접 버튼을 눌러야 하며 30초 이상 방치되면 다시 자동 진행으로 돌아간다. 좁은 화면(≤620px)에서는 YouTube·Kitscript 아이콘 버튼이 메뉴 안의 링크로 옮겨간다(BuntGames 표기는 유지).

## 게임 규칙

- **필드**: 720×1080 고정 논리 해상도(2:3 세로), 창 크기에 맞춰 레터박스·HiDPI 스케일. HUD(스테이지·목숨·점수·크레딧·Lv/XP·폭탄·파워업)는 DOM 칩이라 375px 폰에서도 읽힌다. 고정 60Hz 시뮬레이션.
- **자동 사격**: 함선이 표적을 고르고(낮은 HP·아래쪽·근접·종류별 우선순위·편대 최외곽 가산점) 리드 샷을 쏜다. 발사 방향은 수직 ±15% 콘으로 클램프 — 표적 아래로 이동해야 명중한다. 조준선/십자 표식이 표시된다.
- **편대**: 진입(Galaga식 경로: drop / arc / loop / sweep / spiral / fade) → 편대 이동(벽 반사 시 한 칸 하강, 반사마다 6% 가속, 남은 수가 적을수록 최대 +55% 가속) → 스케줄 다이브(swoop / zag / dash) 후 재진입. 편대가 **위험선(빨간 점선)**에 닿으면 BREACH: 기체 1척 손실 + 편대 230px 후퇴.
- **피격**: 판정은 반경 13px의 작은 코어(그림보다 훨씬 작음, 함선 중앙의 흰 점). 피격 시 2.6초 무적 + **주변 250px의 적탄 삭제**(M4). 목숨 소진 시 스테이지 실패.
- **함선 레벨(XP)**: 스테이지 시작 레벨은 스테이지 데이터(`startLv` 1~6) + 업그레이드 `Veteran Training`. 적 격추 시 기본 HP만큼 XP, 요구치 `10 × 1.38^(Lv-1)`. 레벨당 연사 간격 ×0.93(하한 0.075s), Lv 3·5·7·9·11에서 탄 피해 +1, **Lv4 2연장**, **Lv8 관통탄**, 최대 Lv12. 레벨은 스테이지마다 초기화된다(캠페인 진행이 곧 성장 곡선).
- **별**: ★ 클리어 / ★★ 손실 기체 ≤ 1 / ★★★ 손실 0 + 파(par) 시간 이내. 보너스 스테이지는 점수·크리스털 개수 기준.
- **막힘 방지(현장 지원)**: 같은 스테이지에서 2·4회 연속 실패하면 재도전에 기체 +1·+2, 3·6회 실패하면 폭탄 +1·+2. 실패해도 처치 크레딧의 35%를 받는다.

## 오토 파일럿 AI (데모이자 테스트 봇)

- **회피**: 탄·소행성·지뢰·다이브 중인 적·빔·저격 라인을 짧은 시간축으로 함선 행에 투영해 "차단 셀" 맵을 만들고, 뒤로 가는 DP로 각 (시각, 위치)에서 탈출 가능한 깊이를 구한 뒤 이웃 셀 중 안전하면서 원하는 위치에 가장 가까운 칸으로 한 걸음 이동한다(벙커가 막는 탄은 무시).
- **원하는 위치**: 표적을 발사 콘 안에 두는 최소 이동 → 파워업(가치 판단: 추가 기체 > 실드 > …) → 탄이 많으면 벙커 밑.
- **표적**: 낮은 HP·아래쪽·근접에 종류 가산(저격수·격납고·Aegis·파일런), 편대 최외곽(벽 반사 폭) 가산, 지뢰는 주변 적 수로 평가, 보스는 보호 부위 우선·가려진 코어 감점.
- **폭탄**: 탈출 불가(도둠) 상황 또는 탄이 과도할 때 사용.
- **완벽하지 않음**: 새로 생긴 위협은 반응 시간(0.16s) 이후에야 보고, 3프레임마다만 계획을 갱신하고, 위치 오차를 섞고, 가끔 멈칫한다. 캐주얼 프로필은 반응 0.32s·10프레임 갱신·위치 오차 16px·파워업 절반 무시.
- 자동 상점: 위 빌드 순서. 방치 시 상점 화면에서 9초 후 자동 구매.
